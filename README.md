# Echo Lure — Отблеск

Хоррор-мод для **Minecraft Java Edition 26.3** и **Fabric Loader 0.20.1**. В Верхнем мире появляется летающий помощник в виде маленького жёлтого шарика. Он отвечает на вопросы, запоминает обращение игрока и постепенно уступает место существу, которое сначала наблюдает, а затем охотится.

Это независимая реализация игровой идеи [Verity JE](https://modrinth.com/mod/verity-je-official). У Отблеска собственные реплики, матовый жёлтый шар с минималистичным лицом и отдельная объёмная форма преследователя. Он моргает, шевелит ртом при ответе, радуется аметисту, вздрагивает от удара и хмурится в фазе помех. Диалог по поддерживаемым темам работает полностью локально.

## Установка на этом Mac

1. Закрой Minecraft. В Minecraft Launcher открой **Установки** и проверь профиль **fabric-loader-26.3**. Его версия — `fabric-loader-0.20.1-26.3`, а папка игры — `~/Library/Application Support/minecraft-verity-26.3`.
2. Возьми `echo-lure-1.0.4+mc26.3.jar` из `build/`. Если JAR ещё не собран, выполни `python3 build.py` в корне репозитория.
3. В Finder нажми **⌘⇧G**, введи `~/Library/Application Support/minecraft-verity-26.3/mods` и положи туда JAR. В этой папке уже есть необходимый `fabric-api-0.166.2+26.3.jar`. Если нужно поставить зависимость заново, выбери сборку для 26.3. [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.3)
   При обновлении убери предыдущий JAR Echo Lure из этой же папки.
4. Запусти **fabric-loader-26.3** в Minecraft Launcher, создай тестовый мир в режиме **Выживание** и выполни `/echo status`. Через примерно 25 секунд в Верхнем мире Отблеск пришлёт первое сообщение.

После сборки можно скопировать JAR из терминала.

```bash
cp build/echo-lure-1.0.4+mc26.3.jar "$HOME/Library/Application Support/minecraft-verity-26.3/mods/"
```

Для другого профиля открой его **Папку игры** в Launcher и используй расположенную в ней папку `mods`. Стандартный путь на macOS — `~/Library/Application Support/minecraft/mods`. Для новой установки сначала запусти Minecraft Java 26.3, затем установи Fabric Loader для этой версии. [Установщик Fabric](https://fabricmc.net/use/installer/)

Если команда `/echo status` не появилась, проверь версию и папку игры в Launcher. В `logs/latest.log` этой папки при успешной загрузке будет строка `echo_lure 1.0.4`.

## Как играть

- Нажми ПКМ по Отблеску для подсказки. Чтобы задать вопрос, напиши в чате `Отблеск: где алмазы?` или введи `/echo ask 17 * 6`. Ответ виден тебе. Отблеск знает про алмазы, железо, координаты и время суток и считает простые выражения.
- В фазах контакта и помех ПКМ с аметистовым осколком в основной руке повышает доверие и расходует один осколок в выживании. Удары снижают доверие. При нейтральном доверии три удара с интервалом примерно три секунды доводят Отблеска до ярости. Он злится и через несколько секунд превращается в преследователя. Подарки позволяют выдержать больше ударов до превращения.
- Сначала Отблеск помогает, примерно через 8 минут появляются помехи, около 20-й минуты возникает наблюдатель, а около 40-й начинаются короткие погони с эффектом темноты. Отсчёт идёт, пока игрок бодрствует в Верхнем мире. Прогресс сохраняется отдельно для каждого игрока в каждом мире.
- Для погони нужна сложность выше мирной и персонаж в режиме «Выживание» или «Приключение». Наблюдателю и преследователю нужна свободная площадка неподалёку. Если хочешь увидеть их сразу, встань на открытой местности.

| Команда | Действие |
| --- | --- |
| `/echo status` | Показывает фазу, время и доверие |
| `/echo ask <вопрос>` | Задаёт вопрос Отблеску |
| `/echo stop` | Выключает историю для текущего игрока |
| `/echo start` | После остановки запускает историю с начала |
| `/echo demo guide\|static\|anger\|watch\|hunt\|waiting` | Перезаписывает прогресс выбранной фазой. Требуются читы или права оператора |

Для быстрой проверки открой тестовый мир с читами, введи `/echo demo guide` и задай вопрос. На открытой местности в выживании ударь Отблеска трижды с паузами по три секунды. Команда `/echo demo anger` сразу включает злое выражение и отсчёт до превращения.

## Сборка

Нужны Python 3, Java 25 JDK, установленные Minecraft 26.3 и Fabric Loader 0.20.1, а также JAR Fabric API 0.166.2+26.3. Скрипт использует локальные файлы Minecraft Launcher, автоматически находит его Java 25 на macOS и собирает только файлы этого мода.

```bash
python3 build.py
```

Если Fabric API лежит в другом месте или у Launcher другая папка, передай путь через `--fabric-api` и `--minecraft-dir`. Для отдельного JDK задай `JAVA_HOME`. Результат сборки — `build/echo-lure-1.0.4+mc26.3.jar`.
